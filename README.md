# 🧩 Maze Game (C++)

Это консольная игра-лабиринт на C++, в которой игрок управляет персонажем, собирает монеты и пытается добраться до выхода, избегая монстров.
## 🚀 Возможности

* Управление игроком с клавиатуры (W/A/S/D)
* Случайное движение монстров в отдельном потоке
* Сбор монет и открытие двери при сборе всех монет
* Текстовый рендеринг карты, поля зрения и информации о игроке
* Простая обработка событий с использованием исключений
* Чёткая архитектура (MVC, Observer, Factory, Command)

---

## 🛠️ Технологии

* **C++17**
* Паттерны: MVC, Observer, Factory
* `std::thread`, `std::mutex` для многопоточности
* `std::shared_ptr` для управления памятью
* ООП: наследование, полиморфизм, перегрузка операторов (`+=`, `-=`)

## 📂 Структура проекта

```
myMaze/
 ├── Controller.*      # Управление игроком и монстрами
 ├── Fabric.*          # Фабрики для объектов
 ├── Game.*            # Точка запуска игры
 ├── GameObjects.*     # Игровые объекты (Player, Monster, Wall и др.)
 ├── Maze.*            # Логика лабиринта
 ├── MazeDrawer.*      # Отображение карты
 ├── MyExceptions.*    # Иерархия исключений
 ├── Tile.*            # Клетки поля и система наблюдателей
 ├── __fwd.h           # Forward declarations
 └── Main.cpp          # main()
```

## ▶️ Запуск

1. Скомпилируй проект (пример для `g++`):

   ```bash
   g++ -std=c++17 -pthread myMaze/*.cpp -o maze_game
   ```
2. Запусти исполняемый файл:

   ```bash
   ./maze_game
   ```
3. Игра использует карту `maze.txt`. Пример карты:

   ```
   10 5
   w w w w w w w w w w
   w H 0   M   0   # w
   w   w   w   w   w
   w 0     0       w
   w w w w w w w w w w
   ```

   * `w` — стена
   * `H` — игрок
   * `M` — монстр
   * `0` — монета
   * `#` — дверь

---

## 🎮 Управление

* `W` — вверх
* `A` — влево
* `S` — вниз
* `D` — вправо
